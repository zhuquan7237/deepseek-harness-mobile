# DeepSeek Harness 手机端使用手册

> 适用版本：Android App **0.2.35**  
> 应用包名：`com.dsh.mobile`  
> 配套电脑端：DeepSeek Harness Electron 桌面应用，内含 dsh 引擎与 mobile-bridge 插件。

DeepSeek Harness 手机端让你在手机上连接电脑端，管理会话、发送消息、切换模型和查看任务结果。首次使用前，请先打开电脑端，再完成手机配对。

## 1. 安装与更新

### 1.1 从官网下载 APK

1. **手机浏览器打开 https://relay.zhuquan.xyz/dl ，点 `dsh-mobile.apk` 下载。**  
   本手册对应的最新版本为 **0.2.35**（也可直接下 `dsh-mobile-0.2.35.apk`）。

2. **下载完成后，点开 APK 文件。**  
   系统会进入应用安装页面。

3. **如果系统提示不允许安装此来源的应用，点提示中的设置入口。**  
   仅为本次使用的浏览器或文件管理器允许“安装未知应用”，然后返回安装页面。

4. **点“安装”，完成后点“打开”。**  
   启动 DeepSeek Harness，接下来进行首次配对。

> 官方下载页：**https://relay.zhuquan.xyz/dl**（也有国内直连入口 https://cn.zhuquan.xyz:8443/dl）。只从这两个地址下载，避免来路不明的 APK。安装完成后，可关闭该来源的“安装未知应用”权限。

### 1.2 在应用内更新

应用内更新需要先与电脑端完成配对。

1. **打开手机端“设置”，点“更新检查”。**  
   手机端会从已配对电脑获取更新清单。

2. **发现新版本后，按页面提示点下载或更新操作。**  
   应用会下载 APK，并进行 **SHA-256 校验**，检查下载文件的完整性。

3. **校验通过后，在系统安装页面点“安装”。**  
   按系统提示完成更新，再重新打开应用。

> 更新期间请保持电脑端开启、手机与电脑端连接可用。校验失败时，不要绕过校验安装文件；请重新下载。

## 2. 首次配对

### 2.1 配对前准备

1. **在电脑上打开 DeepSeek Harness 桌面应用，进入手机连接或配对入口。**  
   找到供手机使用的二维码或配对码。入口名称以电脑端实际界面为准。

2. **选择可用的连接方式。**

| 连接方式 | 地址形式 | 使用说明 |
|---|---|---|
| 局域网 | `http://电脑IP:17732` | 首次排查连接时，建议让手机和电脑连接同一 Wi-Fi |
| 公网中继 | `https://cn.zhuquan.xyz:8443/m/<设备密钥>` | 支持国内直连，参考延迟约 60ms，实际取决于网络 |

公网中继由**桌面端主动拨出连接**，家里不需要公网 IP，但电脑端仍需保持开启并联网。

> 不要公开分享包含设备密钥的完整中继地址、配对码或设备令牌。

### 2.2 方法一：扫码配对

1. **在电脑端打开配对二维码。**  
   保持二维码完整显示，方便手机扫描。

2. **在手机端配对页面点扫码入口。**  
   应用会打开相机扫描界面；首次使用时，系统可能请求相机权限。

3. **点“允许”相机权限，将镜头对准电脑上的二维码。**  
   手机会读取二维码中的配对信息。

4. **按页面提示完成确认。**  
   配对成功后，即可访问获授权的会话和功能。

### 2.3 方法二：配对码配对

1. **在电脑端配对入口查看或生成配对码。**  
   配对码为 **8 位**，有效期为 **5 分钟**。

2. **在手机端配对页面点配对码入口，输入完整的 8 位配对码。**  
   输入前检查是否有漏字、多余空格或看错字符。

3. **点页面上的确认或配对操作。**  
   手机端会提交配对请求；按提示完成后即可使用。

4. **如果提示过期，回到电脑端重新获取配对码，再在手机上输入。**  
   过期配对码无法继续使用。

### 2.4 权限说明

权限分为两类，请不要混淆：

**Android 系统权限**

- **相机权限**：用于扫码配对、拍照添加附件。
- **照片或文件访问**：从相册或文件选择器添加附件时，按系统提示授权或选择文件。不同 Android 版本的提示可能不同。
- 拒绝相机权限后，仍可尝试使用**配对码**完成配对。

**设备令牌权限**

手机连接电脑端使用的设备令牌分为以下权限类别：

| 权限 | 类别含义 |
|---|---|
| `read` | 读取类权限 |
| `prompt` | 提交提示、发起模型请求类权限 |
| `config` | 配置类权限 |
| `admin` | 管理类权限 |

具体可执行操作以电脑端授权为准。**配对成功不代表拥有全部权限**；如果某项操作提示无权限，请检查该设备令牌的授权，而不是反复修改 Android 系统权限。

## 3. 主界面导航

手机端主要围绕会话列表、聊天页面、模型配置和设置使用。

### 3.1 会话列表

| 想做什么 | 点哪里 | 会发生什么 |
|---|---|---|
| 打开会话 | 点列表中的会话 | 进入该会话的聊天页面 |
| 查找会话 | 点搜索入口并输入关键词 | 搜索目标会话 |
| 更新列表 | 点刷新操作 | 重新获取会话列表 |
| 修改名称 | 打开目标会话的操作菜单，点重命名 | 输入新名称并确认后，更新会话名称 |
| 开始新对话 | 点新建会话入口 | 创建并进入新会话 |

### 3.2 聊天页面

- **会话标题栏**：显示当前会话使用的模型。
- **消息区域**：查看消息、回复和可展开的思考过程。
- **输入区域**：输入文字、添加附件并发送消息。
- **模型切换入口**：打开模型面板，选择模型、默认模型和思考强度。

### 3.3 模型配置与设置

- **点模型配置入口**：管理提供商、模型和 API Key，测试连接并拉取模型。
- **点设置入口**：调整深色主题、悬浮球开关和检查更新。

## 4. 发消息与停止生成

### 4.1 发送消息

1. **在会话列表点开一个会话，或点新建会话。**  
   进入聊天页面。

2. **点输入框，输入想让模型处理的内容。**  
   发送前可检查标题栏中的当前模型，或先添加附件。

3. **点发送按钮。**  
   请求会通过已配对连接交给电脑端处理，回复显示在消息区域。

### 4.2 停止生成

1. **在回复生成过程中，点停止按钮。**  
   应用会请求停止本次生成。

2. **查看消息区域的最终状态。**  
   网络传输和电脑端处理可能需要时间，请以页面反馈为准。

### 4.3 重新生成

1. **在对应回复的操作区找到“重新生成”，点一下。**  
   应用会重新发起该回复的生成请求。

2. **等待新回复；如果不想继续，点停止。**  
   重新生成也会产生新的模型请求，请留意提供商的用量计费。

## 5. 查看思考过程

思考过程支持折叠显示，避免长内容占满聊天页面。

1. **在包含思考过程的回复中，找到“思考 N 秒”这一行。**  
   折叠状态下，思考过程以这一行展示，`N` 为界面显示的秒数。

2. **点“思考 N 秒”。**  
   展开该回复提供的思考过程内容。

3. **再次点折叠控制区域。**  
   收起内容，回到简洁的一行显示。

> 是否有思考过程可查看，取决于模型和返回内容；不是每条回复都会显示这一项。

## 6. 添加附件

1. **在聊天输入区域点附件入口。**  
   打开附件来源选择。

2. **按需要选择一种方式：**
   - **点“拍照”**：进入相机，拍摄后按提示确认。
   - **点“相册”**：打开图片选择界面，选择已有图片。
   - **点“文件”**：打开文件选择器，选择要添加的文件。

3. **返回聊天页面，确认附件已加入，再输入说明并点发送。**  
   附件会随本次消息提交。

> Android 权限只需在系统提示时按用途授予。附件能否被正确理解，还取决于当前模型的能力。

## 7. 切换模型与思考强度

### 7.1 认识新版模型面板

在聊天页打开模型切换入口后，可以看到：

| 位置或标识 | 用途 |
|---|---|
| **左上角放大镜圆圈** | 搜索模型 |
| **右上角“默认·当前默认模型”胶囊** | 选择默认模型 |
| **思考强度档位** | 调整思考强度 |
| **按供应商分组的模型列表** | 浏览不同供应商下的模型 |
| **模型旁的对勾** | 标记当前选中的模型 |

### 7.2 为当前会话选择模型

1. **打开模型切换面板。**  
   查看按供应商分组的模型列表。

2. **模型较多时，点左上角放大镜圆圈并输入关键词。**  
   搜索要使用的模型。

3. **点目标模型。**  
   当前选中项会显示对勾。

4. **回到聊天页，查看会话标题栏。**  
   确认当前模型名称，再发送下一条消息。

### 7.3 选择默认模型

1. **点面板右上角“默认·当前默认模型”胶囊。**  
   打开默认模型选择入口。

2. **选择想设为默认的模型，并按页面提示完成操作。**  
   右上角胶囊会显示当前默认模型。

> 默认模型与当前会话模型请分别确认。不要仅凭默认模型已修改，就认为已有会话也完成了切换；当前会话以标题栏和列表对勾为准。

### 7.4 调整思考强度

1. **在模型面板找到思考强度档位，点所需档位。**  
   选择本次希望使用的思考强度设置。

2. **确认模型和档位后，返回聊天页发送消息。**  
   实际支持情况与效果取决于当前模型及提供商。

## 8. 配置提供商与模型

进行配置操作前，请确认设备令牌具有相应配置权限。

### 8.1 添加提供商、写入 API Key

1. **打开模型配置页，点添加提供商入口。**  
   新建一个提供商配置。

2. **按页面字段填写提供商信息。**  
   需要填写的参数以界面和提供商文档为准。

3. **点 API Key 输入项，填入该提供商的密钥，并按页面提示保存或确认。**  
   将 API Key 写入配置，供后续调用使用。

> API Key 属于敏感凭据。请勿放入聊天消息、公开截图或发给他人。

### 8.2 测试并拉取模型

1. **在对应提供商配置中点“测试并拉取模型”。**  
   应用会测试该配置，并尝试获取提供商可用的模型列表。

2. **查看测试结果和拉取到的模型。**  
   若失败，先检查 API Key、提供商参数和网络，再重试。

3. **回到聊天页打开模型面板，找到目标供应商分组。**  
   选择要使用的模型，并通过标题栏确认。

### 8.3 手动添加或删除

- **添加模型**：在对应提供商下点添加模型入口，填写界面要求的模型信息并确认，完成模型配置。
- **删除模型**：打开目标模型的管理操作，点删除，并按提示确认。
- **删除提供商**：打开目标提供商的管理操作，点删除，并按提示确认。

删除前请确认不再需要该配置。若当前会话使用的模型已不可用，请重新选择可用模型。

   所需权限以当前设备实际提示为准。

|---|---|
| **单击悬浮球** | 打开或收起气泡 |

## 11. 常见问题

### 11.1 连不上怎么办？

先确认使用的是**局域网**还是**公网中继**，再按顺序排查。

**局域网连接：**

1. **打开手机和电脑的 Wi-Fi 设置，检查是否连接同一 Wi-Fi。**  
   避免手机仍在使用移动数据，或其中一台连到了隔离的访客网络。

2. **回到电脑，确认 DeepSeek Harness 桌面应用仍然开着。**  
   电脑端关闭或电脑休眠时，手机无法正常使用其服务。

3. **检查电脑当前 IP 与连接地址是否一致。**  
   局域网地址应为 `http://电脑IP:17732`；网络变化后电脑 IP 可能改变。

4. **打开电脑防火墙设置，允许 DeepSeek Harness 使用端口 `17732`。**  
   优先为应用或所需端口添加允许规则，不建议直接关闭整个防火墙。

5. **回到手机端重试连接；必要时重新配对。**  
   使用电脑端当前显示的配对信息。

**公网中继连接：**

1. **检查手机和电脑都能正常上网，并保持电脑端开启。**
2. **确认使用的是电脑端提供的完整中继连接信息。**  
   地址形式为 `https://cn.zhuquan.xyz:8443/m/<设备密钥>`，不要自行省略或修改密钥。
3. **返回应用重试；仍失败时重新配对。**  
   中继不要求手机与电脑处于同一 Wi-Fi，也不要求家里有公网 IP。

### 11.2 二维码扫不上怎么办？

1. **打开 Android 应用权限设置，允许 DeepSeek Harness 使用相机。**  
   返回应用后重新打开扫码入口。

2. **在电脑端完整显示二维码，调高屏幕亮度。**  
   避免二维码被遮挡、裁切或反光。

3. **调整手机与屏幕的距离，保持镜头稳定。**  
   让二维码完整进入扫描区域。

4. **仍无法识别时，点配对码入口。**  
   输入电脑端提供的 **8 位配对码**；若已超过 **5 分钟**，重新获取再输入。

### 11.3 更新失败怎么办？

1. **确认已经配对，且电脑端保持开启。**  
   应用内更新需要从已配对电脑获取更新清单并下载 APK。

2. **检查连接和手机剩余存储空间，再点更新检查重试。**  
   下载中断或空间不足都会影响更新。

3. **如果提示 SHA-256 校验失败，重新下载。**  
   不要绕过校验安装该文件。

4. **如果下载成功但系统不允许安装，点系统提示中的设置入口。**  
   为本次安装来源允许“安装未知应用”，然后返回继续安装。

5. **仍无法完成时，从官方官网下载最新版 APK 并尝试安装。**  
   若系统继续报错，保留错误提示以便排查；不要贸然卸载，以免影响本地数据。

### 11.4 能看会话，但不能发消息或修改模型配置？

这可能与**设备令牌权限**有关：

- 读取类操作对应 `read`；
- 发起模型请求类操作对应 `prompt`；
- 配置类操作对应 `config`；
- 管理类操作对应 `admin`。

请在电脑端检查该设备的授权，并按实际需要调整。Android 相机或文件权限无法解决设备令牌权限不足的问题。

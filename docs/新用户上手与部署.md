# DeepSeek Harness 新用户上手与部署

本文面向首次使用者，带你从拿到安装包开始，完成电脑端启动、手机端安装与配对，直到发送第一条消息。

## 1. 准备安装包与运行环境

你需要：

- 一台 Windows 电脑，以及 DeepSeek Harness 电脑端 portable `.exe`。
- 一部 Android 手机，以及手机端 APK。
- 可用的模型配置与对应 API Key；如果尚未配置，可在配对后按本文步骤设置。
- 初次连接建议让手机和电脑接入同一个可信局域网，例如家中的同一个 Wi-Fi。

**产品组成**

| 组件 | 说明 |
|---|---|
| 电脑端 | Electron 桌面应用，内含 dsh 引擎与 mobile-bridge 插件 |
| 手机端 | Android App，包名 `com.dsh.mobile` |
| 手机端当前最新版本 | `0.2.35` |

> 手机端需要连接已配对的电脑。使用期间请保持电脑开机、桌面应用运行，并避免电脑进入休眠。

## 2. 启动电脑端

### 2.1 运行 portable EXE

1. 将电脑端 portable `.exe` 放到便于长期保留的位置。
2. 双击运行，等待桌面应用完成首次启动。
3. 保持应用运行，后续手机连接需要使用其中的 dsh 引擎与 mobile-bridge 插件。

portable 为便携式程序，无需另行安装 dsh 引擎或 mobile-bridge 插件。

### 2.2 允许 Windows 防火墙访问

首次启动时，如果 Windows 弹出防火墙访问提示：

1. 确认弹窗对应的是你刚启动的 DeepSeek Harness。
2. 在可信的家庭或办公局域网中，允许应用通过对应的网络配置文件访问。
3. 点击 **“允许访问”**。

建议优先在可信的“专用网络”中使用，不要为省事关闭整个防火墙，也不要无差别放开公共网络访问。

> 如果当时点了取消，之后仍可在 Windows 防火墙的“允许应用通过防火墙”中调整。局域网连接需要手机能访问电脑的 TCP `17732` 端口。

## 3. 打开“移动端配对”页

在电脑端打开 **“移动端配对”** 页。页面会自动生成：

- **配对二维码**：供手机直接扫描。
- **8 位配对码**：供手机手动输入。

配对码有效期为 **5 分钟**。过期后请使用页面上重新生成的有效配对信息。

扫码前，先确定要使用哪种连接方式。

### 局域网与公网中继如何选择

| 对比项 | 局域网连接 | 公网中继连接 |
|---|---|---|
| 地址形式 | `http://电脑IP:17732` | `https://cn.zhuquan.xyz:8443/m/<设备密钥>` |
| 适用场景 | 手机和电脑在同一可互通的局域网 | 手机在外面、使用移动数据，或不方便局域网直连 |
| 连接路径 | 手机直接访问电脑 | 通过公网中继连接电脑 |
| 网络条件 | 两端局域网互通，电脑允许入站访问 | 两端可访问公网中继 |
| 家里是否需要公网 IP | 不需要 | 不需要，桌面端主动拨出 |
| 延迟说明 | 取决于本地网络 | 国内直连，参考延迟约 `60 ms`，实际以网络状况为准 |

**选择建议：**

- **首次上手、在家或办公室使用：优先局域网。** 路径直接，也便于排查问题。
- **外出使用、手机切换到移动数据：选择公网中继。** 家里不需要公网 IP。
- **同一个 Wi-Fi 仍无法互通：** 检查是否为访客网络、是否开启设备隔离；无法调整时可考虑公网中继。

> 地址中的 `电脑IP` 是电脑的局域网地址；`<设备密钥>` 是占位符。请使用电脑端提供的实际连接信息，不要照抄占位符，也不要公开分享带设备密钥的完整地址。

## 4. 安装 Android App

1. 将 APK 下载或传输到手机。
2. 打开 APK，按系统提示安装。
3. 如果系统要求允许当前浏览器或文件管理器“安装未知应用”，仅对你信任的安装来源授权。
4. 安装完成后打开 DeepSeek Harness 手机端。

核对手机端包名为 `com.dsh.mobile`，当前最新版本为 `0.2.35`。

## 5. 扫码或输入配对码连接

### 推荐：扫码配对

1. 保持电脑端停留在“移动端配对”页。
2. 在手机端选择扫码配对。
3. 按提示授予相机权限。
4. 扫描电脑端显示的二维码，按手机提示完成连接。

### 备选：配对码配对

如果不方便扫码，在手机端选择配对码方式，按页面提示输入电脑端当前显示的 **8 位配对码**。

请在 **5 分钟内**完成操作；如果提示过期，使用新生成的配对码重试。

连接成功后，进入手机端会话列表。

## 6. 发送第一条消息

### 6.1 确认模型可用

如果已经配置好模型，可直接新建会话。

如果尚未配置，且当前设备具备相应配置权限：

1. 打开手机端 **模型配置页**。
2. 添加所需提供商与模型。
3. 写入对应 API Key。
4. 执行测试并拉取模型。

模型配置页也支持删除提供商和模型。请谨慎操作，以免影响后续使用。

### 6.2 选择模型并发送

1. 在会话列表中新建会话。
2. 打开模型切换面板，选择要使用的模型。
3. 检查会话标题栏显示的当前模型。
4. 输入一条简单消息，例如：  
   `你好，请用三句话介绍你能帮我做什么。`
5. 发送消息，等待回复。

能收到回复，即完成从安装到可用的基本流程。

**模型切换面板说明：**

- 左上角放大镜圆圈：搜索模型。
- 右上角 **“默认·当前默认模型”** 胶囊：选择默认模型。
- 思考强度档位：调整思考强度。
- 模型列表：按供应商分组。
- 对勾：标识当前模型。

**聊天中的常用操作：**

- 停止当前生成、重新生成回复。
- 思考过程默认折叠成一行 **“思考 N 秒”**，可展开查看。
- 通过拍照、相册或文件添加附件。
- 在会话列表中搜索、刷新、重命名或新建会话。

## 7. 日常设置与更新

### 外观与提醒

手机端设置支持深色主题、悬浮球开关和更新检查。

“鲸鱼娘”悬浮球可按需开启或关闭：

- 单击：开合气泡。
- 双击：摸头互动。
- 任务完成：气泡提醒。

### 手机端自更新

手机端可从 **已配对电脑**获取更新清单并下载 APK，下载后进行 **SHA-256 校验**。

更新前请确保电脑在线、桌面应用运行且连接正常。校验通过后，再按 Android 系统提示完成安装；若校验失败，不要绕过校验安装该文件。

## 8. 故障排查

### 连不上电脑

按以下顺序检查：

1. **电脑端是否正在运行？**  
   电脑必须开机，DeepSeek Harness 不能已退出。

2. **配对信息是否过期？**  
   配对码只有 5 分钟有效期，过期后重新获取。

3. **连接方式是否匹配当前网络？**  
   手机使用移动数据时，通常无法直接访问家中电脑的局域网地址，应使用公网中继。

4. **局域网是否真正互通？**  
   同一个 Wi-Fi 名称不一定意味着设备可以互相访问。检查访客网络、AP 隔离，以及 VPN 或代理的影响。

5. **电脑 IP 是否变化？**  
   更换网络或重启路由器后，电脑的局域网 IP 可能改变。检查电脑端当前连接信息。

6. **防火墙是否拦截？**  
   确认应用被允许通过当前网络配置文件；局域网模式下检查 TCP `17732` 的访问规则。

7. **公网中继是否可达？**  
   中继模式需要电脑和手机都能访问 `cn.zhuquan.xyz:8443`。检查所在网络是否限制该域名或端口。

### 一直显示“重连中”

“重连中”表示当前连接尚未恢复，可依次检查：

- 手机是否刚切换 Wi-Fi 或移动数据。
- 电脑是否断网、休眠，或桌面应用已退出。
- 中继是否暂时不可达。
- 当前设备是否已在电脑端被吊销。

恢复电脑与网络后等待重连；仍无法恢复时，再使用有效配对信息重新配对。

### 电脑休眠后无法使用

电脑休眠期间无法正常处理手机请求。

- 唤醒电脑并确认桌面应用仍在运行。
- 需要持续远程使用时，可在 Windows 电源设置中按需调整自动休眠策略。
- 笔记本还需检查合盖后的电源行为。

> 公网中继不等于远程唤醒，也不能让已休眠或关机的电脑继续提供服务。

### 防火墙或杀毒软件拦截

- 在 Windows 防火墙中允许 DeepSeek Harness 的必要网络访问。
- 查看杀毒软件的拦截记录、隔离区和网络防护提示。
- 确认安装包来源可信后，再对对应程序作必要放行。

不要通过长期关闭防火墙、关闭杀毒软件或设置整盘排除来解决连接问题。

### 已连接，但消息发不出去

连接成功不代表模型配置一定可用。请检查：

- 是否选择了可用模型。
- 提供商配置、API Key 和测试结果是否正常。
- 电脑是否能访问对应模型服务。
- 当前设备是否具备发送消息所需的权限。

## 9. 安全与设备权限

### 保护配对信息

- 配对码为 **8 位**，**5 分钟过期**。
- 不要把配对二维码、配对码或带设备密钥的中继地址发到公开群聊、截图或日志中。
- 配对码过期仅表示该次配对凭据失效，**不等于已配对设备自动失效**。

### 按需分配权限

设备令牌区分以下权限，具体可用操作以应用内授权为准：

| 权限 | 用途方向 |
|---|---|
| `read` | 读取 |
| `prompt` | 消息与模型请求 |
| `config` | 配置操作 |
| `admin` | 管理操作 |

遵循最小权限原则：仅查看内容的设备不应获得不必要的配置或管理权限。

### 吊销不再信任的设备

手机丢失、借给他人或不再使用时，可在 **电脑端吊销该设备**。如怀疑设备凭据泄露，应及时吊销，不要仅等待配对码过期。

### 注意连接协议

局域网地址使用 `HTTP`，应仅在可信网络中使用，不要将 `17732` 端口随意映射到公网。需要外网访问时，优先使用产品提供的 `HTTPS` 公网中继方式。
